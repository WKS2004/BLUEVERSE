# Individual AI Usage Log Template

Each student should maintain their own AI usage record in accordance with the assignment requirements.

For each meaningful AI-assisted task record:

| Date | Tool/Model | Task | What was generated/advised | What I verified/changed | Evidence |
|---|---|---|---|---|---|
| YYYY-MM-DD | Tool/model | Description | Summary | Tests/review/modifications | Commit/PR/file |

Do not place private credentials, secrets or confidential personal data in the log.
