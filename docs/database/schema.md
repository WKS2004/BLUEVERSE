# Schema Design Status

The v0 repository foundation does not define the final business schema yet.

The initial auth/authorization schema will be designed after the generated ASP.NET services are established.

The eventual schema documentation must include:

- ER diagram
- table definitions
- keys
- relationships
- constraints
- indexes
- audit fields
- migration strategy
- seed data
- Agentic AI workflow-state tables, if required

Business-domain schema should be introduced according to the approved v1/v2/v3 component design rather than prematurely in v0.
