# Marine workflow photographs

These three bundled WebP images are byte-identical copies of the approved
Marine Web assets, shared across BLUEVERSE's two clients:

- `coastal-conditions-hero.webp`: coastal swell and shoreline.
- `coastal-evidence-hero.webp`: a field notebook and compass beside the coast.
- `activity-safety-hero.webp`: kayaking equipment prepared on shore.

The original generation prompts and provenance are recorded in the
[Web asset inventory](../../../../web/src/assets/coastal/marine/README.md).
No new image-generation request was made for the mobile adaptation. Images are
decorative, bundled locally and excluded from accessibility semantics. They
make no claims about current provider readings, stored data or actual safety.
