# Planner imagery

These four assets were newly generated for BLUEVERSE on 2026-10-12 using the
Codex image generation tool and visually selected for the coastal editorial
design. They are illustrative scenes, not photographs of verified destinations,
operators, offerings or the user's actual trips. Do not use them as recommendation
evidence or label them as a specific real location.

| Asset | Intended section | Scene |
| --- | --- | --- |
| `coastal-discovery.webp` | Public introduction hero | Travellers discovering a tropical shoreline |
| `guided-experiences.webp` | Planning benefits | Visitors preparing a guided kayaking outing |
| `trip-preparation.webp` | Creation guide | Bag, water bottle, hat and map ready for a day out |
| `plan-memories.webp` | Personal history and empty history | Journal and coastal photographic prints |

The generated PNGs were encoded to WebP at quality 85 without changing their
composition or dimensions (hero 1024×1536; other images 1536×1024).
React imports these local assets through Vite; no remote image requests are needed.
